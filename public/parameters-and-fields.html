Parameters & Fields

Detailed explanations of all recurring parameters and fields used across the AEAT VERI*FACTU webservice operations.

Overview

This document provides detailed explanations of all recurring parameters and fields used across the AEAT VERI*FACTU webservice operations. Understanding these parameters is crucial for successful integration.

Core Parameters

Flow control (TiempoEsperaEnvio)

The client must always use the TiempoEsperaEnvio value returned by AEAT in the previous response. Wait exactly t seconds or until your batch limit is reached, whichever happens first. Treat any hardcoded wait values as examples only — never as normative guidance.

NIF Validation

Spanish Tax Identification Numbers (NIF) must follow specific format rules:

Individual NIF (Persona Física)

  • Format: 8 digits + 1 letter
  • Example: 12345678Z
  • Check digit: Calculated using Spanish algorithm

Company NIF (Persona Jurídica)

  • Format: 1 letter + 7 digits + 1 letter
  • Example: A12345674
  • Check digit: Calculated using Spanish algorithm

Date Formats

Date Format

  • Format: YYYY-MM-DD
  • Example: 2024-01-15
  • Timezone: UTC recommended

DateTime Format

  • Format: YYYY-MM-DDTHH:MM:SS
  • Example: 2024-01-15T10:30:00
  • Timezone: UTC recommended

Amount Validation

All monetary amounts must follow specific validation rules:

Precision

2 decimal places maximum

Range

Positive values only

Currency

EUR (implicit)

Invoice Number Validation

Invoice numbers must follow specific format rules:

Length

1-60 characters

Characters

Alphanumeric and common symbols

Uniqueness

Must be unique per issuer
