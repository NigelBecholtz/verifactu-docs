Register Invoice (Alta)

Overview

The Alta operation is used to register invoices with the Spanish tax authority (AEAT) for verification. This is the primary operation for invoice verification and must be performed before sending invoices to customers.

Purpose

  • Real-time Validation: Validate invoice data against Spanish tax rules
  • CSV Generation: Generate secure verification codes for invoices
  • Compliance: Ensure compliance with Spanish tax regulations
  • Fraud Prevention: Prevent tax fraud through verification

HTTP Request Details

Method & Endpoint

POST https://prewww1.aeat.es/wlpl/TIKE-CONT/ws/SistemaFacturacion/VerifactuSOAP

Required Headers

Content-Type: text/xml; charset=utf-8
SOAPAction: ""
Important: SOAPAction must be an empty string (as per WSDL), not "urn:VeriFactu/Alta"

Authentication

Mutual TLS with FNMT certificate required

Request Format

SOAP 1.1 XML envelope with invoice data

XML Namespaces

xmlns:soapenv="http://schemas.xmlsoap.org/soap/envelope/"
xmlns:ver="urn:aeat:verifactu:schema"

Required Fields

Header Information (Cabecera)

  • NIFEmisor: Issuer tax identification number
  • FechaEnvio: Submission timestamp (ISO 8601, e.g. 2025-11-07T10:00:00)
  • TiempoEsperaEnvio: Wait time requested by AEAT (positiveInteger)
  • TipoComunicacion: Operation type (Alta, Baja, Consulta)
  • NumeroRegistro / Observaciones: Optional metadata returned by AEAT

Invoice Data (Registro)

  • Serie & NumFactura: Invoice identification
  • FechaExpedicion: Issue date (YYYY-MM-DD)
  • ImporteTotal: Total amount of the invoice
  • DetalleDesglose: Tax breakdown, base imponible and cuota per rate
  • Encadenamiento & Huella: Hash chain data required by AEAT
  • SistemaInformatico: Software identifier, version and installation number

Success Response Fields:

  • EstadoEnvio: Overall operation status (Correcto, ParcialmenteCorrecto, Incorrecto)
  • CSV: Secure verification code for the invoice
  • EstadoRegistro: Per-invoice registration status
  • Resumen: Summary of processed invoices

Error Response

<soapenv:Envelope xmlns:soapenv="http://schemas.xmlsoap.org/soap/envelope/">
  <soapenv:Header/>
  <soapenv:Body>
    <soapenv:Fault>
      <faultcode>soapenv:Client</faultcode>
      <faultstring>Cabecera inválida: FechaEnvio ausente</faultstring>
      <detail>
        <ver:Codigo xmlns:ver="urn:aeat:verifactu:schema">Error-001</ver:Codigo>
        <ver:Descripcion xmlns:ver="urn:aeat:verifactu:schema">FechaEnvio es obligatoria</ver:Descripcion>
      </detail>
    </soapenv:Fault>
  </soapenv:Body>
</soapenv:Envelope>

Error Response Fields:

  • faultcode: SOAP fault code (soap:Server, soap:Client)
  • faultstring: Human-readable error description
  • CodigoError: AEAT-specific error code
  • DescripcionError: Detailed error description

Error Handling

Common Error Codes

Validation Errors

  • 1001: Invalid NIF format
  • 1002: Invalid invoice number
  • 1003: Invalid amount format

System Errors

  • 2001: Service temporarily unavailable
  • 2002: Database connection error
  • 2003: Authentication failed

Implementation Example

Node.js Implementation

const https = require('https');
const fs = require('fs');

const options = {
  key: fs.readFileSync('client-key.pem'),
  cert: fs.readFileSync('client-cert.pem'),
  ca: fs.existsSync('ca-cert.pem') ? fs.readFileSync('ca-cert.pem') : undefined,
  hostname: 'prewww1.aeat.es',
  port: 443,
  path: '/wlpl/TIKE-CONT/ws/SistemaFacturacion/VerifactuSOAP',
  method: 'POST',
  headers: {
    'Content-Type': 'text/xml; charset=utf-8',
    'SOAPAction': ''
  }
};

// TiempoEsperaEnvio must mirror the value returned in the last AEAT response.
const waitTimeFromPreviousResponse = 60; // example placeholder

const soapBody = `<?xml version="1.0" encoding="UTF-8"?>
<soapenv:Envelope xmlns:soapenv="http://schemas.xmlsoap.org/soap/envelope/"
                  xmlns:ver="urn:aeat:verifactu:schema">
  <soapenv:Header/>
  <soapenv:Body>
    <ver:MensajeAlta>
      <ver:Cabecera>
        <ver:NIFEmisor>B12345678</ver:NIFEmisor>
        <ver:FechaEnvio>2025-11-07T10:00:00</ver:FechaEnvio>
        <ver:TiempoEsperaEnvio>${waitTimeFromPreviousResponse}</ver:TiempoEsperaEnvio>
        <ver:TipoComunicacion>Alta</ver:TipoComunicacion>
      </ver:Cabecera>
      <ver:Registros>
        <ver:Registro>
          <ver:Serie>F2025</ver:Serie>
          <ver:NumFactura>000123</ver:NumFactura>
          <ver:FechaExpedicion>2025-11-07</ver:FechaExpedicion>
          <ver:ImporteTotal>121.00</ver:ImporteTotal>
        </ver:Registro>
      </ver:Registros>
    </ver:MensajeAlta>
  </soapenv:Body>
</soapenv:Envelope>`;

const req = https.request(options, (res) => {
  let data = '';
  res.on('data', chunk => {
    data += chunk;
  });
  res.on('end', () => {
    console.log('Response:', data);
  });
});

req.on('error', (error) => {
  console.error('Error:', error);
});

req.write(soapBody);
req.end();

Important: SOAPAction Header

The SOAPAction header must be an empty string (""), not "urn:VeriFactu/Alta". According to the WSDL, the operation uses soapAction="". Using an incorrect SOAPAction will result in error code 4118: "la dirección no se corresponde con el fichero de entrada."

Testing Environment

Always test with the test environment first before using production. The test environment URL is: https://prewww1.aeat.es/wlpl/TIKE-CONT/ws/SistemaFacturacion/VerifactuSOAP
